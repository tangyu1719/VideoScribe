TLINKER GUI - PySide6 优化计划                                                                                                                                                    │
│                                                                                                                                                                                   │
│ Context                                                                                                                                                                           │
│                                                                                                                                                                                   │
│ 项目中现有的链接分析 GUI 是 Tkinter 实现的（src/agent/unified_link_document_gui.py），界面风格简陋。Flet GUI                                                                      │
│ 中的链接分析页面（flet_gui/main_app.py:build_link_page）只是一个占位符。需要用 PySide6 重写一个功能完整、视觉精美的链接分析 GUI。                                                 │
│                                                                                                                                                                                   │
│ 风格要求：科技浅色透明蓝、卡片化、圆角化、立体化。                                                                                                                                │
│                                                                                                                                                                                   │
│ 后端依赖                                                                                                                                                                          │
│                                                                                                                                                                                   │
│ 已存在的后端模块（复用，不修改）：                                                                                                                                                │
│ - src/agent/link_analyzer.py - LinkAnalyzer 类，分析小红书/抖音/通用链接                                                                                                          │
│ - src/agent/unified_link_document_processor.py - UnifiedLinkDocumentProcessor，统一处理入口                                                                                       │
│ - src/agent/multimodal_gui.py - FILE_TYPE_CONFIG 和 get_file_type 工具函数                                                                                                        │
│                                                                                                                                                                                   │
│ 实现方案                                                                                                                                                                          │
│                                                                                                                                                                                   │
│ 新建文件                                                                                                                                                                          │
│                                                                                                                                                                                   │
│ 1. flet_gui/tlinker_gui/theme.py - 主题样式配置                                                                                                                                   │
│ - 定义科技浅色透明蓝配色方案                                                                                                                                                      │
│ - 主色：#1890FF，浅蓝背景：#E6F7FF，玻璃背景：#F0F7FFB0                                                                                                                           │
│ - 提供 QSS（Qt Style Sheet）片段：卡片样式、按钮样式、输入框样式、进度条样式                                                                                                      │
│ - 定义圆角（8-16px）、阴影（QGraphicsDropShadowEffect）、渐变等工具函数                                                                                                           │
│                                                                                                                                                                                   │
│ 2. flet_gui/tlinker_gui/tlinker_app.py - 主应用                                                                                                                                   │
│ - PySide6 主窗口，带左侧导航栏 + 右侧内容区                                                                                                                                       │
│ - 导航项：链接分析、文档处理、历史记录、AI 配置                                                                                                                                   │
│ - 页面切换逻辑                                                                                                                                                                    │
│                                                                                                                                                                                   │
│ 3. flet_gui/tlinker_gui/link_analysis_page.py - 链接分析页面（核心）                                                                                                              │
│ - 卡片化布局：                                                                                                                                                                    │
│   - 输入卡片：URL 输入框 + 平台自动识别标签                                                                                                                                       │
│   - 操作卡片：分析按钮（渐变蓝色）、批量导入                                                                                                                                      │
│   - 结果卡片：标题、平台、类型、图片数量等元信息                                                                                                                                  │
│   - 内容卡片：提取的文本内容（Markdown 风格显示）                                                                                                                                 │
│   - 图片卡片：缩略图网格展示                                                                                                                                                      │
│   - AI 分析卡片：AI 摘要结果                                                                                                                                                      │
│   - 进度卡片：QProgressBar + 状态标签                                                                                                                                             │
│ - 多线程处理（QThread），避免阻塞 UI                                                                                                                                              │
│ - 实时日志输出到 QTextEdit                                                                                                                                                        │
│                                                                                                                                                                                   │
│ 4. flet_gui/tlinker_gui/document_page.py - 文档处理页面                                                                                                                           │
│ - 文件拖放区域                                                                                                                                                                    │
│ - 文件类型徽章显示                                                                                                                                                                │
│ - 处理进度 + 结果展示                                                                                                                                                             │
│                                                                                                                                                                                   │
│ 5. flet_gui/tlinker_gui/__init__.py - 包初始化                                                                                                                                    │
│                                                                                                                                                                                   │
│ 视觉设计细节                                                                                                                                                                      │
