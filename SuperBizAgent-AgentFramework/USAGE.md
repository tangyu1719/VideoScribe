## 1. 安装与配置

### 1.1 Python 环境

确保安装 Python 3.8 或更高版本：

```bash
python --version
```

### 1.2 安装依赖

```bash
cd SuperBizAgent-AgentFramework
pip install -r requirements.txt
```

### 1.3 安装 FFmpeg

**Windows:**
1. 访问 https://ffmpeg.org/download.html
2. 下载 ffmpeg.exe
3. 将 ffmpeg 添加到系统 PATH

**验证安装:**
```bash
ffmpeg -version
```

### 1.4 数据库配置（可选）

如果使用 MariaDB 持久化配置：

1. 安装 MariaDB 10.6+
2. 创建数据库：
```sql
CREATE DATABASE video_agent CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

3. 配置数据库连接：
   - 编辑 `src/agent/db_config.json`
   - 填写数据库地址、用户名、密码

### 1.5 获取 API 密钥

#### 1.5.1 火山引擎 AI API

1. 访问火山引擎控制台
2. 创建应用，获取 API Key
3. 记录接入点 ID（endpoint_id）

#### 1.5.2 百度 OCR API

1. 访问百度 AI 开放平台
2. 创建应用，获取 APP_ID、API_KEY、SECRET_KEY

#### 1.5.3 飞书 API

1. 访问飞书开放平台
2. 创建企业自建应用
3. 获取 APP ID 和 APP Secret
4. 获取 Folder Token（需要访问飞书文档 API）

## 3. 功能详解

### 3.1 视频链接处理

#### 3.1.1 支持的链接类型

- **抖音**: 视频/图文
- **小红书**: 视频/图文
- **B 站**: 视频
- **YouTube**: 视频
- **微信公众号**: 文章

#### 3.1.2 处理流程

1. **输入链接**
   - 在"视频链接"输入框中粘贴链接
   - 示例：`https://www.xiaohongshu.com/explore/xxx`

2. **选择工作流**
   - 默认："链接文档化流程"
   - 可在"设置" → "任务编排"中创建自定义流程

3. **执行流程**
   - 点击"执行流程"按钮
   - 系统自动执行以下步骤：

#### 3.1.3 自动处理步骤

**步骤 1: 链接分析**
```
[00:00:01] 开始分析小红书链接...
[00:00:02] 小红书内容类型检测结果：xiaohongshu
[00:00:02] ✓ 检测到小红书图文，继续图文分析...
```

**步骤 2: 内容提取**
- 图文：提取图片链接 + OCR 识别
- 视频：下载视频 → 语音转文字

**步骤 3: AI 分析**
```
[00:00:10] 文档大小：35000 字符，设置超时时间：3 分钟
[00:00:10] 调用火山引擎 API 进行总结... (尝试 1/3)
[00:00:10]   使用主接入点：ep-20260320202115-9jqfp
[00:00:15] 火山引擎 API 调用成功（主接入点）
```

**步骤 4: 生成文档**
```
[00:00:16] Markdown 文档生成成功：OUTPUT/001-04-14-xxx.md
```

**步骤 5: 飞书上传（可选）**
```
[00:00:17] 文档已上传到飞书：xxx_token
```

### 3.2 多模态文档处理

#### 3.2.1 支持的文件格式

- **文档**: PDF、DOC、DOCX、PPT、PPTX
- **表格**: XLS、XLSX、CSV
- **图片**: JPG、PNG、GIF、BMP
- **文本**: TXT、MD

#### 3.2.2 处理方式

1. **MinerU 处理**（推荐）
   - 高精度 PDF 解析
   - 保留公式、表格、图表

2. **本地解析**
   - 简单文件处理
   - 快速提取文本

#### 3.2.3 使用步骤

1. 切换到"多模态"标签页
2. 点击"选择文件"或拖拽文件
3. 选择处理方式
4. 点击"处理"
5. 查看结果

### 3.3 知识库管理

#### 3.3.1 创建知识库

1. 切换到"知识库"标签页
2. 点击"创建知识库"
3. 输入知识库名称
4. 选择向量模型：
   - BAAI/bge-large-zh-v1.5（中文推荐）
   - paraphrase-multilingual-MiniLM-L12-v2（多语言）

#### 3.3.2 上传文档

1. 选择知识库
2. 点击"上传文档"
3. 选择文件（支持批量）
4. 选择分块策略：
   - 按段落分块
   - 按句子分块
   - 递归分块
   - 固定大小分块

#### 3.3.3 构建索引

1. 点击"构建索引"
2. 等待向量化完成
3. 查看索引统计

#### 3.3.4 RAG 检索

1. 在"AI 问答"标签页输入问题
2. 系统自动从知识库检索相关片段
3. AI 基于检索结果生成答案

### 3.4 任务编排

#### 3.4.1 创建流程

1. 点击"设置" → "任务编排"
2. 点击"新建流程"
3. 输入流程名称

#### 3.4.2 添加节点

1. 从节点中心拖拽节点到画布
2. 配置节点参数
3. 连接节点（输出 → 输入）

#### 3.4.3 可用节点

- **链接分析**: 分析链接类型
- **视频下载**: 下载视频
- **语音转文字**: Whisper 转写
- **OCR 识别**: 百度 OCR
- **AI 分析**: 火山引擎 AI
- **生成 MD**: Markdown 文档
- **飞书上传**: 上传到飞书

#### 3.4.4 保存流程

1. 点击"保存"
2. 流程会自动同步到数据库
3. 在主界面的工作流下拉框中选择

## 4. 高级配置

### 4.1 AI API 配置

#### 4.1.1 添加主备接入点

1. 点击"设置" → "AI API 配置"
2. 主配置：
   - 名称：火山引擎 - 主
   - 接入点 ID：`ep-20260320202115-9jqfp`
   - URL: `https://ark.cn-beijing.volces.com/api/v3`
   - API Key: `your_api_key`

3. 添加备选配置：
   - 点击"添加备选配置"
   - 填写信息
   - 保存

#### 4.1.2 配置说明

- **自动切换**: 主接入点失败自动切换备用
- **动态超时**: 根据文档大小自动调整（1-4 分钟）
- **重试机制**: 失败后最多重试 3 次

### 4.2 OCR API 配置

1. 点击"设置" → "OCR API 配置"
2. 填写百度 OCR 配置：
   - APP_ID
   - API_KEY
   - SECRET_KEY
3. 保存

### 4.3 飞书配置

1. 点击"设置" → "AI 设置" → "飞书配置"
2. 填写：
   - APP ID
   - APP Secret
   - Folder Token
   - 默认文件夹路径
3. 启用"飞书功能"

### 4.4 数据库配置

#### 4.4.1 配置文件

编辑 `src/agent/db_config.json`:

```json
{
  "host": "localhost",
  "port": 3306,
  "user": "root",
  "password": "your_password",
  "database": "video_agent"
}
```

#### 4.4.2 数据同步

- 配置会同时保存到数据库和 config.json
- 确保数据库、配置文件、代码三者一致

### 4.5 日志配置

#### 4.5.1 日志级别

- INFO: 普通信息
- WARNING: 警告
- ERROR: 错误
- DEBUG: 调试信息（默认关闭）

#### 4.5.2 日志文件

日志自动保存到：
- `maintenance_records/` 目录
- 自动生成维护建议

## 5. 故障排除

### 5.1 API 调用失败

**现象:**
```
[主] 接入点失败 [ArkRateLimitError]: Error code: 429
```

**解决方案:**

1. **检查账户限制**
   - 登录火山引擎控制台
   - 查看用量统计
   - 确认是否达到限制

2. **切换备用接入点**
   - 系统会自动切换
   - 或手动在配置中更换

3. **等待后重试**
   - 部分限制是暂时的
   - 等待几分钟后重试

### 5.2 视频下载失败

**现象:**
```
No video formats found
```

**解决方案:**

1. **检查链接有效性**
   - 在浏览器中打开链接
   - 确认视频存在

2. **更新 yt-dlp**
   ```bash
   pip install -U yt-dlp
   ```

3. **检查网络**
   - 某些平台需要特殊网络环境
   - 使用代理或镜像

### 5.3 OCR 识别失败

**现象:**
```
触发 QPS 限制
```

**解决方案:**

1. **降低频率**
   - 系统已自动添加 1.5 秒延迟
   - 避免批量并发

2. **升级配额**
   - 登录百度 AI 控制台
   - 提升 QPS 限制

### 5.4 飞书上传失败

**现象:**
```
上传到飞书失败：Invalid token
```

**解决方案:**

1. **检查 Token**
   - 确认 Folder Token 有效
   - Token 可能过期，重新获取

2. **检查权限**
   - 应用是否有文档写入权限
   - 在飞书开放平台添加权限

3. **检查文件夹**
   - 确认文件夹存在
   - 确认有访问权限

### 5.5 日志延迟

**现象:**
日志显示比实际操作慢 30 秒以上

**解决方案:**

1. **已修复**
   - 最新版本已改为同步写入
   - 如果仍有延迟，检查系统资源

2. **检查 CPU 使用率**
   - 高 CPU 使用率可能导致 GUI 更新延迟
   - 关闭其他占用资源的程序

### 5.6 数据库连接失败

**现象:**
```
无法连接到数据库
```

**解决方案:**

1. **检查数据库服务**
   ```bash
   # Linux
   sudo systemctl status mariadb
   
   # Windows
   检查服务管理器中的 MariaDB 服务
   ```

2. **检查配置**
   - 确认 db_config.json 配置正确
   - 确认用户名密码正确

3. **检查网络**
   - 如果是远程数据库，检查网络连接
   - 确认防火墙允许 3306 端口
